# 0ero Gravity Art

## Bauhaus in Zero Gravity: A Web3 Art Experience

0ero Gravity Art reimagines Bauhaus design principles for the blockchain age, creating an immersive, interactive showcase for Bauhaus-inspired NFT collections. By liberating geometric forms from the constraints of gravity, we create a new dimension of artistic expression that honors the Bauhaus legacy while embracing web3 innovation.

![Zero Gravity Bauhaus](assets/preview.jpg)

## Project Overview

This project creates an interactive web experience where:

- Bauhaus-inspired geometric elements float in a zero-gravity environment
- Users can influence the movement of shapes with their cursor
- Multiple collections of Bauhaus artwork are showcased in an immersive gallery
- NFTs are stored on IPFS/Arweave and connected to the Solana blockchain
- Collectors can view and purchase pieces through established marketplaces

## Collections

### Bauhaus Buildings
Architectural visualizations exploring form, function, and space, liberated from gravitational constraints.

### Geometric Abstractions
Pure form compositions using primary colors and basic shapes, the fundamental vocabulary of Bauhaus design.

### Color Play
Explorations of color theory and relationships central to Bauhaus principles, presented in dynamic formats.

## Technical Features

- **Three.js** for interactive 3D visualization
- **IPFS/Arweave** for decentralized storage
- **Solana** blockchain integration
- **Responsive design** for all devices
- **Cursor-reactive** elements
